# Requirements

- Build an independent Spanish language archive of documented controversies and failures associated with José Antonio Kast's government.
- Recreate the observed clawd.rip experience: chronological entries, reversible sorting, expanded context, external sources, and a persistent dark theme with the D shortcut.
- Use Chilean government blue `#0f69b4` and red `#eb3c46`, with an original identity that does not imply government affiliation.
- Include responsive layouts, keyboard navigation, search, category filters, deep links, and clear empty and failure states.
- Every published entry must include a dated source, attributed reporting, and context. Distinguish a controversy, an allegation, and a proposed measure from a proven outcome.
- Use BBCL (BioBioChile), Diario Financiero, El Ciudadano, EL PAÍS, and Radio Universidad de Chile for Chilean news reporting. Published news source URLs must belong to biobiochile.cl, df.cl, elciudadano.com, elpais.com, or radio.uchile.cl. The government color manual is a design reference.
- Contributions are private browser drafts with JSON export; do not imply that a server or moderation inbox receives them.
- Do not fabricate statistics, vote counts, testimonials, evidence, or completed moderation.
- Keep credentials, generated captures, test artifacts, runtime state, logs, and local notes outside Git. Do not read .env. Do not add code comments.
- Keep README.md and PLAN.md current. Test filtering, persistence failure, input handling, and key browser interactions.
- Deliver the local project and publish an owner-private preview through Sites when available.
